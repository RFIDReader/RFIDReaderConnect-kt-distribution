MultiplexRFIDReaderDelegate

class MultiplexRFIDReaderDelegate(delegates: List<RFIDReaderDelegate>) : RFIDReaderDelegate

Fans every RFIDReaderDelegate callback out to an ordered list of children.

RFIDReader accepts only one delegate. When you need more than one observer (e.g. a native ViewModel and the web bridge), wrap them and hand the multiplex delegate to the reader.
