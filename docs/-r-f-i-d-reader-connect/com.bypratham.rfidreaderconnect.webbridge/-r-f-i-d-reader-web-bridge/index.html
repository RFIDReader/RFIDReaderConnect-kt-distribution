RFIDReaderWebBridge

class RFIDReaderWebBridge @JvmOverloads constructor(context: Context, val handlerName: String = "rfidBridge", readerProvider: () -> RFIDReader?, additionalDelegates: List<RFIDReaderDelegate> = emptyList(), onReaderCreated: (RFIDReader) -> Unit? = null, deviceScanner: RFIDReaderDeviceScanner? = null) : RFIDReaderDelegate

Bridges an Android WebView mini-program to the RFIDReader SDK.

Usage:

val bridge = RFIDReaderWebBridge(
    context = appContext,
    handlerName = "rfidBridge",
    readerProvider = { appState.reader },
    onReaderCreated = { appState.reader = it },
    deviceScanner = BLEDeviceScanner(appContext),
)
bridge.installOn(webView)

From JavaScript (the injected client library is available at window.RFIDReader):

await RFIDReader.connect({ model: "MARK3-HH7", transport: { type: "ble", identifier: "AA:BB:CC:DD:EE:FF" } })
RFIDReader.on("tag", (t) => console.log(t.epc))
await RFIDReader.startAsyncInventory()

If the WebView doesn't support DOCUMENT_START_SCRIPT, callers must invoke injectScript from their own WebViewClient.onPageStarted — the bridge logs a warning in that case.
