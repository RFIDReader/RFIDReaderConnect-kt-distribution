RFIDReader

class RFIDReader(model: RFIDReaderModel, val name: String? = null, transport: TransportType, delegate: RFIDReaderDelegate) : RFIDReaderProtocol, TransportDelegate, AsyncInventoryParserDelegate

Primary SDK entry point. Mirrors the iOS RFIDReader class 1:1 in API surface and semantics.

Buffer parsing runs on a dedicated HandlerThread (rfid-parsing) so transport receive callbacks are serialized without blocking BLE / socket threads. All delegate callbacks are dispatched on the Android main thread (parity with iOS DispatchQueue.main.async).
